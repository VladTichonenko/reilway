# Руководство для менеджера: база знаний и промпты бота

## Какой файл редактировать

**Единственный файл для наполнения бота — это `bot-knowledge.json`.**

Путь к файлу в проекте: **`bot-knowledge.json`** (в корне проекта, рядом с `ai-service.js`).

Все изменения в этом файле подхватываются ботом при следующем запросе к AI (перезапуск сервера не обязателен, если приложение перечитывает файл при каждом запросе; иначе — перезапустите бота после правок).

---

## Что можно редактировать в `bot-knowledge.json`

### 1. База знаний платформы (уже есть)

- **`guide_for_sellers`** — гайд для продавцов: верификация, тарифы, шаги продажи, доп. сервисы.
- **`technical_specification`** — как работает предаукцион и аукцион: правила, ставки, уведомления, приоритеты.
- **`share_purchase_guide`** — как работает покупка долей: ценообразование, что видит клиент, выгоды.

Менеджер может:
- править тексты в `title`, `content`, `description`, `steps`, `benefits` и т.п.;
- добавлять новые пункты в массивы `sections`, `tariffs`, `rules`, `faq` и т.д.;
- не удалять ключи верхнего уровня (`guide_for_sellers`, `technical_specification`, `share_purchase_guide`), иначе бот может сломаться.

Структуру (какие поля есть в каждом блоке) лучше сохранять, меняя только содержимое.

---

### 2. Дополнительные промпты для бота (новый блок)

В `bot-knowledge.json` добавлен блок **`additional_prompts`**. В нём два подраздела:

#### 2.1. `instructions` — дополнительные правила для бота

Массив строк. Каждая строка — отдельное правило, которое бот обязан учитывать в ответах.

**Пример в файле:**

```json
"additional_prompts": {
  "description": "Дополнительные инструкции для бота...",
  "instructions": [
    "При упоминании акций или спецпредложений — уточнять срок действия и условия.",
    "Если клиент спрашивает про рассрочку — направлять на контакт менеджера для индивидуального обсуждения."
  ],
  ...
}
```

**Что сюда писать:**
- как бот должен вести себя в конкретных ситуациях (акции, рассрочка, жалобы);
- что обязательно говорить или не говорить;
- куда направлять клиента (сайт, email, менеджер).

Можно добавлять и удалять строки в массиве `instructions`. Синтаксис JSON: строки в кавычках, между элементами — запятые, последний элемент без запятой.

---

#### 2.2. `faq` — частые вопросы и ответы

Массив объектов с полями `question` и `answer`. Бот использует их, когда вопрос клиента совпадает по смыслу с `question`.

**Пример в файле:**

```json
"faq": [
  {
    "question": "Как связаться с поддержкой?",
    "answer": "Напишите на support@sellyourbrick.com или оставьте заявку на сайте."
  },
  {
    "question": "Есть ли доставка документов?",
    "answer": "Документы передаются в электронном виде и при необходимости по согласованию с менеджером."
  }
]
```

**Что сюда писать:**
- типичные вопросы клиентов и короткие, чёткие ответы;
- контакты, сроки, условия, которые должны быть едиными во всех ответах.

Добавляйте новые объекты в массив `faq`, сохраняя формат `"question": "..."`, `"answer": "..."`.

---

## Правила при редактировании JSON

1. **Не ломать JSON:** после каждой строки или значения — запятая, кроме последнего элемента в блоке. Кавычки в строках — двойные `"`.
2. **Кодировка:** сохранять файл в UTF-8.
3. **Проверка:** после правок можно проверить файл на сайте [jsonlint.com](https://jsonlint.com) (вставить содержимое и нажать Validate).

## Краткая шпаргалка: что в каком блоке

| Блок в `bot-knowledge.json` | Назначение |
|-----------------------------|------------|
| `guide_for_sellers`         | Гайд для продавцов: верификация, тарифы, шаги продажи. |
| `technical_specification`   | Правила предаукциона и аукциона, ставки, уведомления. |
| `share_purchase_guide`     | Покупка долей: цены, условия, что видит клиент. |
| `additional_prompts.instructions` | Доп. правила для бота (как отвечать, куда направлять). |
| `additional_prompts.faq`   | Вопрос–ответ для типовых запросов. |

---

## Итог для менеджера

- Редактируется **только один файл:** **`bot-knowledge.json`**.
- В нём менеджер наполняет **базу знаний** (гайды, спецификация, доли) и **дополнительные промпты** (правила в `instructions` и пары вопрос–ответ в `faq`).
- После сохранения файла достаточно перезапустить бота (если он не подхватывает изменения на лету), чтобы новые тексты и правила начали использоваться в ответах.
